= Documentation README

PacketFence documentation uses http://www.methods.co.nz/asciidoc/[AsciiDoc] format.

Converting documentation to PDF or HTML requires these tools:

* https://asciidoctor.org/[asciidoctor] (.asciidoc to .html)
* https://asciidoctor.org/docs/asciidoctor-pdf/[asciidoctor-pdf] (.asciidoc to .pdf)
* https://github.com/rouge-ruby/rouge[rouge] (syntax highlighter)

Use the repository Makefile to call these tools:

* Generate PDF documents:

  make pdf

* Generate HTML documents:

  make html
