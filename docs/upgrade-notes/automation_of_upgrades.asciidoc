//== Automation of upgrades

Upgrade automation available since PacketFence 11.0.0 for **same-OS upgrades**.

## OS Support Matrix

**PacketFence 14.0.0+ OS Changes:**
- **Discontinued**: Debian 11 (bullseye) support
- **New**: Debian 12 (bookworm) support  
- **Continued**: RedHat EL8 support

## Upgrade Paths by Operating System

### RHEL 8 Systems
- **In-place automated upgrades**: **SUPPORTED**
- **Versions**: PacketFence 11.0.0+ → latest
- **Method**: Standard automation process

### Debian Systems
- **Debian 11**: **NOT SUPPORTED** (end-of-life)
- **Debian 12**: **SUPPORTED** for PacketFence 14.0.0+
- **Migration required**: Debian 11 → fresh Debian 12 install + import/export

=== Automation Scope and Limitations

**Supported Configurations:**
* **Standalone servers only** - Clusters use manual procedures
* Exportable configuration backup created automatically
* Pre-upgrade steps executed per upgrade documentation

**Current Automation Support:**
* **RHEL 8**: PacketFence 11.0.0+ → latest version **SUPPORTED**
* **Debian 12**: PacketFence 14.0.0+ → latest version **SUPPORTED**
* **OS Migration**: Requires fresh installation + export/import **NOT AUTOMATED**

=== Full upgrade (for PacketFence version 11.0.0 only - see next section for 11.1.0 and above)

==== Preliminary steps

On PacketFence version 11.0.0, install the `packetfence-upgrade` package using following instructions:

.RHEL / CentOS based systems **only**
[source,bash]
----
yum install packetfence-upgrade --enablerepo=packetfence
----

.Debian systems **only**
[source,bash]
----
apt update
apt install packetfence-upgrade
----

Then perform a full upgrade using following command:

[source,bash]
----
/usr/local/pf/addons/full-upgrade/run-upgrade.sh
----

=== Full upgrade (for PacketFence versions 11.1.0 and later)

Run following script to perform a full upgrade:

[source,bash]
----
/usr/local/pf/addons/upgrade/do-upgrade.sh
----
