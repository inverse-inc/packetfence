[[pfconnector]]
==== PacketFence Connector

The PacketFence Connector establishes a secure connection, tunneled over
HTTPS, between the network equipment of a remote site and a PacketFence
server, for instance a Cloud-hosted one: RADIUS (MAB, 802.1X), the captive
portal, access reevaluation (RADIUS CoA/Disconnect, SNMP), LDAP and RADIUS
sources, NTLM authentication and device profiling through the Fingerbank
Collector.

It is a PacketFence plugin, installed on the PacketFence server:

[source,bash]
----
pfcmd plugin install ./packetfence-plugin-pfconnector_<version>_amd64.deb
----

The package `packetfence-plugin-pfconnector` installs the server of the
tunnels (`packetfence-pfconnector-server`), the connector of the PacketFence
server itself (`packetfence-pfconnector-client`), and the _Cloud Connectors_
section of the administration interface (_Configuration -> Network
Configuration -> Cloud Connectors_). The connectors of the remote sites run
the package `packetfence-pfconnector-remote`.

Both packages, and the documentation of the PacketFence Connector (the
installation of a remote connector, its configuration, high availability,
site networking, remote terminal, upgrades), are in
https://github.com/akainverse/pfconnector. Once installed, the documentation
of the plugin is in
[filename]`/usr/local/packetfence-plugin-pfconnector/docs/README.md`.

Without the plugin, the settings that send traffic through a connector (_Use
connector_ of the switches, the authentication sources, the domains and the
firewall SSO) find no connector and the traffic is sent directly.
