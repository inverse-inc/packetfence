== About this Guide

This guide covers PacketFence installation and day-to-day administration. It
provides comprehensive instructions for system requirements assessment, initial
deployment, network integration, authentication configuration, and ongoing
maintenance. The guide covers both standalone and distributed deployments,
including certificate management, database configuration, and integration with
external authentication systems like Active Directory and LDAP.

== Introduction

PacketFence is a fully supported, trusted, Free and Open Source network access
control (NAC) system. It features a captive portal for registration and
remediation, centralized wired and wireless management, 802.1X support, layer-2
isolation of problematic devices, and integration with IDS, vulnerability
scanners and firewalls. PacketFence effectively secures networks from small to
very large heterogeneous environments. Visit https://www.packetfence.com for more
details.
