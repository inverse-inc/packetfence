//== Development environment setup

Set up your development environment to run sources from `/usr/local/pf`.

Deploy a Debian 13 (trixie) machine. Other operating systems are not supported
for development environments.

NOTE: If you're running on Linode, disable Network helper:
https://www.linode.com/docs/guides/network-helper/

Find current devel version number at:
https://github.com/inverse-inc/packetfence/blob/devel/conf/pf-release

IMPORTANT: This example will use version `99.9` as the example version number.

Install PacketFence from the Debian repository:

[source,bash]
----
apt install gnupg sudo curl
curl -fsSL https://inverse.ca/downloads/GPG_PUBLIC_KEY | gpg --dearmor -o /etc/apt/keyrings/packetfence.gpg
echo "deb [signed-by=/etc/apt/keyrings/packetfence.gpg] https://inverse.ca/downloads/PacketFence/debian/99.9 trixie trixie" > /etc/apt/sources.list.d/packetfence.list
apt update
apt install linux-headers-$(uname -r)
apt install packetfence
git config --global --add safe.directory /usr/local/pf
----

Now, you must go through the configurator and validate you can login into the admin interface at the end.

Next, run:

[source,bash]
----
bash /usr/local/pf/addons/dev-helpers/setup-dev-env.sh
----

You will now have to wait for 10-15 minutes after the startup so that all container images are built (they're built on runtime when using a dev environment)
