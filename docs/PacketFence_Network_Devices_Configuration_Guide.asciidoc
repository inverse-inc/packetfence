== About this Guide

This guide covers network device configuration for VLAN enforcement with
PacketFence. Switches, wireless controllers and wireless access points are
considered network devices in PacketFence.

Find the latest version at https://packetfence.org/documentation/

== Note on Inline enforcement support

Inline enforcement does not require this guide, except for RADIUS inline. RADIUS
inline uses a flat layer-2 network on PacketFence's inline interface with no
other gateway for Internet access.

Use this technique when network hardware does not support VLAN enforcement.

== Note on RADIUS accounting

Enabling RADIUS accounting on network devices significantly increases database
size and may cause performance issues. Use RADIUS accounting only if absolutely
required.
