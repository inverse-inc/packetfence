//=== Huawei

==== AC6605 Controller

PacketFence supports this controller with the following technologies:

[options="compact"]
* Wireless 802.1X
* Wireless MAC Authentication

===== Controller configuration

Setup NTP server:

	<AC>system-view
	[AC] ntp-service unicast-server 208.69.56.110

Setup the radius server (@IP of PacketFence) authentication + accounting:

[NOTE]
===============================
In this configuration I will use the ip address of the VIP of PacketFence:
192.168.1.2; Registration VLAN : 145, Isolation VLAN : 146
===============================

	<AC>system-view
	[AC] radius-server template radius_packetfence
	[AC-radius-radius_packetfence] radius-server authentication 192.168.1.2 1812
	weight 80
	[AC-radius-radius_packetfence] radius-server accounting 192.168.1.2 1813 weight
	80
	[AC-radius-radius_packetfence] radius-server shared-key cipher s3cr3t
	[AC-radius-radius_packetfence] undo radius-server user-name domain-included
	[AC-radius-radius_packetfence] quit
	[AC] radius-server authorization 192.168.1.2 shared-key cipher s3cr3t
	server-group radius_packetfence
	[AC] aaa
	[AC-aaa] authentication-scheme radius_packetfence
	[AC-aaa-authen-radius_packetfence] authentication-mode radius
	[AC-aaa-authen-radius_packetfence] quit
	[AC-aaa] accounting-scheme radius_packetfence
	[AC-aaa-accounting-radius_packetfence] accounting-mode radius
	[AC-aaa-accounting-radius_packetfence] quit
	
	[AC-aaa] domain your.domain.com
	[AC-aaa-domain-your.domain.com] authentication-scheme radius_packetfence
	[AC-aaa-domain-your.domain.com] accounting-scheme radius_packetfence
	[AC-aaa-domain-your.domain.com] radius-server radius_packetfence
	[AC-aaa-domain-your.domain.com] quit
	[AC-aaa] quit

===== Create an Secure dot1x SSID

Activate the dotx globally:

	<AC>system-view
	[AC] dot1x enable

Create your secure dot1x ssid:

Configure WLAN-ESS 0 interfaces:
	
	[AC] interface Wlan-Ess 0
	[AC-Wlan-Ess0] port hybrid untagged vlan 145 to 146
	[AC-Wlan-Ess0] dot1x enable
	[AC-Wlan-Ess0] dot1x authentication-method eap
	[AC-Wlan-Ess0] permit-domain name your.domain.com
	[AC-Wlan-Ess0] force-domain name your.domain.com
	[AC-Wlan-Ess0] default-domain your.domain.com
	[AC-Wlan-Ess0] quit

===== Configure AP parameters:
	
Configure radios for APs:

	[AC] wlan
	[AC-wlan-view] wmm-profile name huawei-ap
	[AC-wlan-wmm-prof-huawei-ap] quit
	[AC-wlan-view] radio-profile name huawei-ap
	[AC-wlan-radio-prof-huawei-ap] radio-type 80211gn
	[AC-wlan-radio-prof-huawei-ap] wmm-profile name huawei-ap
	[AC-wlan-radio-prof-huawei-ap] quit
	[AC-wlan-view] ap 1 radio 0
	[AC-wlan-radio-1/0] radio-profile name huawei-ap
	Warning: Modify the Radio type may cause some parameters of Radio resume defaul
	t value, are you sure to continue?[Y/N]: y
	[AC-wlan-radio-1/0] quit
	
Configure a security profile named huawei-ap. Set the security policy to WPA
authentication, authentication method to 802.1X+PEAP, and encryption mode to
CCMP:

	[AC-wlan-view] security-profile name huawei-ap-wpa2
	[AC-wlan-sec-prof-huawei-ap-wpa2] security-policy wpa2
	[AC-wlan-sec-prof-huawei-ap-wpa2] wpa-wpa2 authentication-method dot1x
	encryption-method ccmp
	[AC-wlan-sec-prof-huawei-ap-wpa2] quit

Configure a traffic profile:

	[AC-wlan-view] traffic-profile name huawei-ap
	[AC-wlan-wmm-traffic-huawei-ap] quit

Configure service sets for APs, and set the data forwarding mode to direct
forwarding:

The direct forwarding mode is used by default.
	
	[AC-wlan-view] service-set name PacketFence-dot1x
	[AC-wlan-service-set-PacketFence-dot1x] ssid PacketFence-Secure
	[AC-wlan-service-set-PacketFence-dot1x] wlan-ess 0
	[AC-wlan-service-set-PacketFence-dot1x] service-vlan 1
	[AC-wlan-service-set-PacketFence-dot1x] security-profile name huawei-ap-wpa2
	[AC-wlan-service-set-PacketFence-dot1x] traffic-profile name huawei-ap
	[AC-wlan-service-set-PacketFence-dot1x] forward-mode tunnel
	[AC-wlan-service-set-PacketFence-dot1x] quit

Configure VAPs and deliver configurations to the APs:

	[AC-wlan-view] ap 1 radio 0
	[AC-wlan-radio-1/0] service-set name PacketFence-dot1x
	[AC-wlan-radio-1/0] quit
	[AC-wlan-view] commit ap 1

===== Create your Open ssid

Activate the mac-auth globally:

	<AC>system-view
	[AC] mac-authen
	[AC] mac-authen username macaddress format with-hyphen
	[AC] mac-authen domain your.domain.com

Create your Open ssid:

Configure WLAN-ESS 1 interfaces:

	[AC] interface Wlan-Ess 1
	[AC-Wlan-Ess1] port hybrid untagged vlan 145 to 146
	[AC-Wlan-Ess1] mac-authen
	[AC-Wlan-Ess1] mac-authen username macaddress format without-hyphen
	[AC-Wlan-Ess1] permit-domain name your.domain.com
	[AC-Wlan-Ess1] force-domain name your.domain.com
	[AC-Wlan-Ess1] default-domain your.domain.com
	[AC-Wlan-Ess1] quit

Configure AP parameters:

Configure a security profile named huawei-ap-wep. Set the security policy to WEP
authentication.
	
	[AC]wlan
	[AC-wlan-view] security-profile name huawei-ap-wep
	[AC-wlan-sec-prof-huawei-ap-wep] security-policy wep
	[AC-wlan-sec-prof-huawei-ap-wep] quit

Configure service sets for APs, and set the data forwarding mode to direct
forwarding:

The direct forwarding mode is used by default.
	
	[AC-wlan-view] service-set name PacketFence-WEP
	[AC-wlan-service-set-PacketFence-WEP] ssid PacketFence-Open
	[AC-wlan-service-set-PacketFence-WEP] wlan-ess 1
	[AC-wlan-service-set-PacketFence-WEP] service-vlan 1
	[AC-wlan-service-set-PacketFence-WEP] security-profile name huawei-ap-wep
	[AC-wlan-service-set-PacketFence-WEP] traffic-profile name huawei-ap (already
	created before)
	[AC-wlan-service-set-PacketFence-WEP] forward-mode tunnel
	[AC-wlan-service-set-PacketFence-WEP] quit

Configure VAPs and deliver configurations to the APs:

	[AC-wlan-view] ap 1 radio 0
	[AC-wlan-radio-1/0] service-set name PacketFence-WEP
	[AC-wlan-radio-1/0] quit
	[AC-wlan-view] commit ap 1

==== S6700 Switch

PacketFence supports this switch with the following technologies:

[options="compact"]
* Wireless 802.1X
* Wireless MAC Authentication
* Wired MAC Authentication
* Wired 802.1X
* Web Authentication (External Captive Portal)

===== Web Authentication

The Web Authentication feature uses an ACL-based approach to redirect
unregistered devices to the PacketFence captive portal. When a device is
in an unregistered state, the switch intercepts HTTP traffic and
redirects the device to the external portal. Once the device is
registered, PacketFence returns a different ACL that grants normal
network access.

This workflow is functionally equivalent to the Cisco WLC Web Auth
approach.

[NOTE]
===============================
In this configuration we use the following IP addresses:
PacketFence management (VIP): 192.168.1.2;
Registration VLAN: 145; Isolation VLAN: 146;
PacketFence portal URL: http://192.168.1.2/Huawei::S6700
===============================

===== Create ACLs for Web Authentication

Create a pre-authentication ACL that allows only DHCP, DNS, and traffic
to the PacketFence server. This ACL name will be used as the
registration role in PacketFence:

	[S6700] acl name Pre-Auth-WebRedirect 3000
	[S6700-acl-adv-Pre-Auth-WebRedirect] rule permit udp destination-port eq 67
	[S6700-acl-adv-Pre-Auth-WebRedirect] rule permit udp destination-port eq 68
	[S6700-acl-adv-Pre-Auth-WebRedirect] rule permit udp destination-port eq 53
	[S6700-acl-adv-Pre-Auth-WebRedirect] rule permit ip destination 192.168.1.2 0
	[S6700-acl-adv-Pre-Auth-WebRedirect] rule deny ip
	[S6700-acl-adv-Pre-Auth-WebRedirect] quit

Create a post-authentication ACL that allows all traffic:

	[S6700] acl name Authorize_any 3001
	[S6700-acl-adv-Authorize_any] rule permit ip
	[S6700-acl-adv-Authorize_any] quit

===== Create the Web Authentication SSID

Enable MAC authentication globally:

	<S6700>system-view
	[S6700] mac-authen
	[S6700] mac-authen username macaddress format with-hyphen
	[S6700] mac-authen domain your.domain.com

Configure a WLAN-ESS interface with MAC authentication for web
authentication:

	[S6700] interface Wlan-Ess 2
	[S6700-Wlan-Ess2] port hybrid untagged vlan 145 to 146
	[S6700-Wlan-Ess2] mac-authen
	[S6700-Wlan-Ess2] mac-authen username macaddress format without-hyphen
	[S6700-Wlan-Ess2] permit-domain name your.domain.com
	[S6700-Wlan-Ess2] force-domain name your.domain.com
	[S6700-Wlan-Ess2] default-domain your.domain.com
	[S6700-Wlan-Ess2] quit

Configure a security profile with an open security policy for the
captive portal SSID:

	[S6700] wlan
	[S6700-wlan-view] security-profile name huawei-webauth
	[S6700-wlan-sec-prof-huawei-webauth] security-policy open
	[S6700-wlan-sec-prof-huawei-webauth] quit

Configure the service set for web authentication:

	[S6700-wlan-view] service-set name PacketFence-WebAuth
	[S6700-wlan-service-set-PacketFence-WebAuth] ssid PacketFence-WebAuth
	[S6700-wlan-service-set-PacketFence-WebAuth] wlan-ess 2
	[S6700-wlan-service-set-PacketFence-WebAuth] service-vlan 1
	[S6700-wlan-service-set-PacketFence-WebAuth] security-profile name huawei-webauth
	[S6700-wlan-service-set-PacketFence-WebAuth] traffic-profile name huawei-ap
	[S6700-wlan-service-set-PacketFence-WebAuth] forward-mode tunnel
	[S6700-wlan-service-set-PacketFence-WebAuth] quit

Bind the service set to the AP radio and commit:

	[S6700-wlan-view] ap 1 radio 0
	[S6700-wlan-radio-1/0] service-set name PacketFence-WebAuth
	[S6700-wlan-radio-1/0] quit
	[S6700-wlan-view] commit ap 1

===== PacketFence configuration

Add the Huawei S6700 switch in the PacketFence administration interface:

[options="compact"]
* Navigate to *Configuration -> Policies and Access Control -> Switches*
* Click *New Switch*
* Enter the IP address of the S6700
* Set the *Type* to `Huawei::S6700`
* Set the *Mode* to `production`
* In the *RADIUS* tab, enter the RADIUS shared secret matching
  the one configured on the switch

Configure the external portal enforcement:

[options="compact"]
* In the *Roles* tab, enable *Role by Web Auth URL*
* Set the *registration* URL to:
  `http://<your_packetfence_hostname>/Huawei::S6700`
* This URL must match the external portal URL pattern used by
  PacketFence to identify Huawei S6700 requests

Configure the roles to match the ACL names defined on the switch:

[options="compact"]
* In the *Roles* tab, configure the following role mappings:
** *registration* role: `Pre-Auth-WebRedirect`
** *default* role: `Authorize_any`

These role values correspond to the ACL names on the switch and will be
sent in the `Huawei-Redirect-ACL` RADIUS attribute in the
Access-Accept response. When a device is unregistered, PacketFence
returns the `Pre-Auth-WebRedirect` ACL along with the portal redirect
URL (via `Huawei-Portal-UR`) and a URL redirect flag
(`Huawei-URL-Flag` set to 1). Once the device completes registration
through the captive portal, PacketFence sends a Change of Authorization
(CoA) to the switch, triggering re-authentication. The subsequent
Access-Accept will include the `Authorize_any` ACL, granting the
device full network access.

[NOTE]
===============================
The default CoA and disconnect port for the Huawei S6700 is 3799. If
you need to change this, update the *CoA Port* and *Disconnect Port*
settings in the switch configuration in PacketFence.

The S6700 module uses RADIUS CoA with the vendor-specific attribute
`HW-Ext-Specific = "user-command=1"` for re-authentication, or RADIUS
Disconnect-Request for deauthentication when there are open security
events.
===============================
